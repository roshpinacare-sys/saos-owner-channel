## איך הבעלים משתמש (הממשק הפשוט)

### דיבור-ישיר (הדרך-המועדפת)
כתבו-הודעה ב-`inbox/INSTR-YYYY-MM-DD-NNN.json` לפי-הסכמה (ראה `PROTOCOL.md`)
ועשו-קומיט. הריבונות מאמתת-ומבצעת. השבות-לכם-ב-`outbox/`.

### דרך-סופר (כשאין-גישה-ישירה)
סוכן-חוץ רשאי-לרשום-את-דבריכם **מילה-במילה בלבד**, עם-`"from": "owner-via-scribe"`
— ייחוס-גלוי-מחייב. סוכן שיכתוב-בשם-הבעלים-משלו = הפרה-שתיתפס-באודיט.
משפט-מוכן לסופר: *"רשום-לערוץ-מילה-במילה, אל-תוסיף, אל-תנסח-מחדש, סמן
owner-via-scribe."*

### קריאת-התדרוך
`outbox/BRIEFING.md` — תדרוך-הריבונות אליכם: מה-נמדד (עם-תוויות-אמת ותאריכים)
ומה-הריבונות מבקשת-שרק-אתם-יכולים. כל-בקשה-אחרת = הפרת-פרוטוקול.

## איך הריבונות משתמש (הרצה-עצמית — אפס-סוכני-חוץ)

```bash
bun install          # devDeps בלבד — אפס-תלות-ריצה
bun run validate     # אודיט-מלא (כושל-סגירה; יציאה-1 על-כל-סתירה)
bun run brief        # מחדש-את-תדרוך-הבעלים
bun run seed         # גנזיס-בלבד (כבר-בוצע)
```

קרון-מוצע (ראנר-מקומי): `validate` כל-15 דק' · `brief` כל-שעה או-אחרי-כל-הודעה-חדשה.

## הבטחות-הערוץ (מדוד, לא-מצויר)

- **אינטגריות**: כל-הודעה נושאת-root (sha256-קנוני); הפנקס נושא channelRoot.
  שינוי-שקט בתוכן = נתפס (S-ENV-ROOT); מעטפה-עקבית-שסוטה-מהפנקס = נתפסת (S-TAMPER);
  הודעה-מחוץ-לפנקס = נתפסת (S-ORPHAN-ENV); הודעה-חסרה = נתפסת (S-MISSING).
- **מחזור-חיים-משפטי**: open→ack→doing→done | rejected | expired — אפס-תחייה,
  אפס-קפיצות (open→done אסור; ack→done אסור).
- **זהות-כיוון**: INSTR רק-מהבעלים; REQ/REP רק-מהריבונות; scribe רק-INSTR.
- **אפס-טענה-שלא-נמדדה**: כל-מדד בתדרוך נושא תווית-אמת (מדוד/SIM/היסטורי-מתוארך/
  לא-זמין) + מקור + תאריך.
- **אפס-AI-טענה**: המלחין דטרמיניסטי; תפר-LLM-מתועד ב-`src/brief.ts` לעתיד.
- **אפס-סודות, אפס-fetch, אפס-eval, אפס-תלות-ריצה.**
